Authentication

POST /api/admin/auth/login

Authenticate an admin user and receive a JWT token.

Request Body

Parameter Type Description
username string Admin username required
password string Admin password required

Response

{
  "success": true,
  "admin": { "id": "...", "username": "admin", ... },
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "expiresAt": "2026-01-23T16:00:00.000Z"
}
GET /api/admin/auth/me Auth Required

Get current authenticated admin user details.

Leads

POST /api/enterprise/leads

Create a new lead from the website form.

Request Body

ParameterTypeDescription
companystringCompany name required
namestringContact name required
emailstringContact email required
phonestringPhone number
titlestringJob title
industrystringIndustry sector
sizestringCompany size (1-10, 11-50, 51-200, etc.)
GET /api/enterprise/leads Auth Required

Get all leads with optional filters.

Query Parameters

ParameterTypeDescription
statusstringFilter by status (new, contacted, qualified, etc.)
prioritystringFilter by priority (hot, warm, cold)
tierstringFilter by recommended tier
PUT /api/enterprise/leads/:id Auth Required

Update a lead's information.

Deals

POST /api/enterprise/deals Auth Required

Create a new deal from a lead.

Request Body

ParameterTypeDescription
leadIdstringID of the lead required
tierstringPricing tier (startup, growth, enterprise, etc.)
seatsnumberNumber of seats
discountnumberDiscount percentage (0-100)
GET /api/enterprise/deals Auth Required

Get all deals with optional status filter.

PUT /api/enterprise/deals/:id Auth Required

Update a deal. Set status to 'won' or 'lost' to close the deal.

Proposals

POST /api/proposals Auth Required

Create a new proposal for a lead or deal.

GET /api/proposals Auth Required

Get all proposals.

POST /api/proposals/:id/send Auth Required

Mark a proposal as sent.

POST /api/proposals/:id/accept

Accept a proposal (client endpoint).

Get available demo time slots.

POST /api/scheduling/demos

GET /api/scheduling/demos Auth Required

Get all scheduled demos.

GET /api/scheduling/upcoming Auth Required

Analytics

GET /api/admin/analytics/overview Auth Required

Get comprehensive dashboard metrics including revenue, leads, deals, and conversion rates.

GET /api/admin/analytics/mrr Auth Required

Get MRR/ARR metrics and growth rates.

GET /api/admin/analytics/funnel Auth Required

Get sales funnel data.

Get revenue trend over time.

ParameterTypeDescription

Notifications

GET /api/admin/notifications Auth Required

Get notifications for the authenticated admin.

POST /api/admin/notifications/:id/read Auth Required

Mark a notification as read.

POST /api/admin/notifications/read-all Auth Required

Mark all notifications as read.

WebSocket: Connect to wss://up.doz.com.im/ws/admin?token=YOUR_TOKEN for real-time notifications.

Webhooks

GET /api/admin/webhooks Auth Required

Get all configured webhooks.

POST /api/admin/webhooks Auth Required

Create a new webhook.

Request Body

ParameterTypeDescription
namestringWebhook name required
urlstringWebhook URL required
eventsarrayEvents to subscribe to required

Available Events

lead.created, lead.updated, lead.qualified
deal.created, deal.updated, deal.won, deal.lost
proposal.created, proposal.sent, proposal.accepted
demo.scheduled, demo.completed
payment.received, payment.failed

Backups

GET /api/admin/backups Auth Required

List all available backups.

POST /api/admin/backups Auth Required

Create a manual backup.

GET /api/admin/backups/stats Auth Required

Get backup statistics and next scheduled backup time.

Data Export

GET /api/admin/export/:type Auth Required

Export data in CSV or JSON format.

Path Parameters

ParameterDescription
typeleads, deals, proposals, affiliates, demos, activities, transactions

Query Parameters

ParameterTypeDescription
formatstringcsv or json (default: csv)
