Keyboard Shortcuts

Beginner 3 min read

Screenshot Capture

These shortcuts work globally when the DOZ UP desktop app is running:

Action Shortcut
Quick Capture (Region) CtrlShiftS
Full Screen Capture CtrlShiftF
Active Window CtrlShiftW
Delayed Capture (3s) CtrlShiftD

Studio Editor

When editing images in Studio:

Action Shortcut
Undo CtrlZ
Redo CtrlY
Save CtrlS
Copy CtrlC
Delete Selection Delete or Backspace
Select All CtrlA

Upload Page

Action Shortcut
Paste from Clipboard CtrlV
Browse Files CtrlO

Gallery Navigation

Action Shortcut
Next Image → or J
Previous Image ← or K
Close Preview Esc
Focus Search /

Mac Users

Replace Ctrl with Cmd for all shortcuts on macOS.

Pro Tip

You can customize all shortcuts in Settings > Keyboard. Set up shortcuts that don't conflict with your other applications.
