Gallery Management

Beginner 5 min read

Your Image Library

The Gallery is your personal library of all uploaded images. Access it anytime to view, manage, or share your screenshots and uploads.

Gallery Features

Search

Find images quickly by filename, date, or tags

Filter

Filter by date range, file type, or visibility status

Grid & List View

Switch between thumbnail grid and detailed list views

Bulk Selection

Select multiple images for batch operations

Image Actions

Click on any image to open it and access these actions:

  • View full-size image
  • Copy share link
  • Edit in Studio
  • Download original
  • Set privacy (public/private)
  • Delete permanently

Organizing Tips

Keep your gallery organized with these tips:

  • Use descriptive filenames before uploading
  • Regularly delete images you no longer need
  • Set sensitive screenshots to private
  • Use the search feature instead of scrolling

Pro Tip

Images are synced across all your devices. Access your gallery from any device by logging in to your DOZ UP account.
